## 🚀 Quick Start (3 Steps)

### 1️⃣ Execute SQL Schema
```
1. Go to: https://app.supabase.com
2. SQL Editor → New Query
3. Copy: backend/database/schema.sql
4. Click: Run
```

### 2️⃣ Start Frontend
```bash
npm run dev
```
Open: **http://localhost:8443**

### 3️⃣ Start Backend
```bash
cd backend
npm start
```
Runs on: **http://localhost:5000**

**✅ Done! App is ready to use.**
